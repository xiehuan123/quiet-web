# Triage Labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Waiting for essential information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready to implement |
| `ready-for-human` | `ready-for-human` | Requires human-only work |
| `wontfix` | `wontfix` | Intentionally not being implemented |

New specs and tickets created from the accepted brief use `ready-for-agent` without another triage pass.
