# 广告净化

这是一个可直接本地加载的 Chrome Manifest V3 扩展。它使用一组随版本维护的小规模网络规则减少已知广告请求，并只对满足多项证据、且不在保护区内的广告容器做可逆隐藏。

## 本地加载

1. 打开 `chrome://extensions`，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本项目根目录下的 `extension/`，不要选择 `source/`。
4. 打开普通 HTTP/HTTPS 页面，点击工具栏中的“广告净化”。

当前可直接加载目录：`/Users/xiehuan/Desktop/浏览器插件/quiet-web/extension`

## 使用

- 总开关同时控制网络规则与页面隐藏；关闭后页面改动立即恢复，网络请求需刷新页面后恢复。
- “暂停本站”只放行当前页面显示的精确 hostname，不自动包含其他子域名；暂停后页面改动立即恢复，网络请求需刷新。
- “管理暂停列表与使用边界”打开设置页，可移除单项或清空列表。
- 所有设置只保存在本机，不上传页面内容。

## 边界

本扩展不承诺全网 100% 无广告。它不会仅凭 `position: fixed`、dialog、overlay 或名称含 `ad`/`popup` 就隐藏元素，也不会绕过正文、导航、登录、验证码、支付、安全提示、cookie 选择或付费墙。生产包不包含第三方整包过滤列表，也不联网下载规则。
